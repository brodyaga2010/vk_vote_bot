# VK Vote Bot

VK-бот на `vkbottle` для голосования на мероприятии
«Юридическая Жемчужина России. Пермский край 2026».

## Что умеет

- ведёт пользователя строго по сценарию голосования;
- красиво приветствует и объясняет шаги;
- показывает кнопки для выбора ряда и места;
- просит подтвердить выбранные ряд и место перед голосом;
- проверяет корректность ряда и места;
- не принимает случайные символы и просит повторить ввод на том же шаге;
- не даёт повторно голосовать ни с того же места, ни тому же VK-пользователю;
- показывает участниц кнопками;
- считает голоса и отдаёт администраторам красивую статистику;
- поддерживает кнопки и команды `Начать голосование`, `Помощь`, `Статус`, `Итоги`, `Остановить`;
- пишет основные действия в консольные логи.

## Локальный запуск

1. Создайте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

2. Установите зависимости:

```bash
python3 -m pip install --upgrade pip
python3 -m pip install -e .
```

3. Заполните переменные окружения:

```bash
export VK_BOT_TOKEN="ваш_токен"
export VK_ADMIN_IDS="123456789,987654321"
```

4. Запустите бота:

```bash
python3 -m bot.main
```

## Docker Compose

1. Подготовьте файл `.env` рядом с `docker-compose.yml`:

```bash
VK_BOT_TOKEN=ваш_токен
VK_ADMIN_IDS=123456789,987654321
```

2. Запустите контейнер:

```bash
docker compose up -d --build
```

3. Посмотреть логи:

```bash
docker compose logs -f
```

4. Остановить:

```bash
docker compose down
```

Каталог `bot/data` подключается как volume, поэтому `valid_seats.json` и `votes.json`
сохраняются между перезапусками контейнера.

Если бот был остановлен администратором кнопкой `Остановить`, для повторного запуска:

```bash
rm -f bot/data/bot_stopped.flag
docker compose up -d --build
```

## Команды администратора

- `Статус` — бот отвечает, что работает, и показывает число сохранённых голосов.
- `Итоги` — бот отправляет подробную статистику по всем финалисткам и помечает лидера.
- `Остановить` — выключает бота и оставляет Docker-контейнер в режиме ожидания без автоподъёма бота.

## Пользовательский сценарий

1. Пользователь нажимает `Начать голосование`.
2. Бот показывает кнопки с рядами.
3. Бот показывает кнопки с местами только для выбранного ряда.
4. Пользователь подтверждает выбранные ряд и место.
5. Бот показывает кнопки с финалистками.
6. После голосования бот благодарит и блокирует повторную попытку.

## Тесты и проверка

```bash
python3 -m unittest discover -s tests -v
python3 -m compileall bot tests
```

## Где хранятся данные

- `bot/data/valid_seats.json` — разрешённые места для голосования;
- `bot/data/votes.json` — уже сохранённые голоса.

## Важно перед мероприятием

- Проверьте, что у сообщества включён `Long Poll API`.
- Проверьте, что в `VK_ADMIN_IDS` указаны реальные VK ID администраторов.
- Если до этого были тестовые голоса, очистите `bot/data/votes.json` перед началом реального голосования.
